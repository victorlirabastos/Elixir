# Estudos de Elixir

Este diretório reúne implementações desenvolvidas durante
a disciplina de Programação Funcional.

## Objetivos

- Praticar a sintaxe da linguagem Elixir.
- Compreender os conceitos de Programação Funcional.
- Resolver listas de exercícios propostas na disciplina.
- Documentar as soluções desenvolvidas.

## Organização

As atividades serão organizadas em diretórios separados
por lista de exercícios.

Cada lista poderá conter:

- Arquivos de implementação (.ex ou .exs).
- Documentação das soluções.
- Exemplos de entrada e saída.
