# Elixir

Repositório dedicado ao estudo e desenvolvimento de projetos utilizando a linguagem de programação Elixir.

## Objetivos

- Aprender os fundamentos da linguagem Elixir.
- Aplicar conceitos do paradigma de Programação Funcional.
- Desenvolver soluções para listas de exercícios acadêmicos.
- Criar projetos práticos para aprofundar os conhecimentos na linguagem.

## Estrutura do repositório

```text
Elixir/
├── estudos_elixir/
│   └── README.md
└── projetos/
    └── README.md
```

### Estudos Elixir

Diretório destinado às atividades e listas de exercícios da disciplina de Programação Funcional.

### Projetos

Diretório destinado ao desenvolvimento de projetos independentes utilizando Elixir.

## Tecnologias

- Elixir
- Erlang/OTP
