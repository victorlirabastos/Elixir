# Projetos em Elixir

Diretório destinado ao desenvolvimento de projetos
independentes utilizando a linguagem Elixir.

## Objetivos

- Desenvolver aplicações práticas.
- Explorar recursos da linguagem Elixir.
- Aplicar conceitos de Programação Funcional.
- Construir projetos para o portfólio de programação.

## Organização

Cada projeto será armazenado em seu próprio diretório,
contendo código-fonte e documentação.
